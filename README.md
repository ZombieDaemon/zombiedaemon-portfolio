🚀 Run Locally

1. Clone the repository:
   
   git clone https://github.com/YOUR-GITHUB-USERNAME/zombiedaemon-portfolio.git

2. Open the project folder:
   
   cd zombiedaemon-portfolio

3. Open "index.html" in your browser.
   
   Alternatively, use the Live Server extension in Visual Studio Code for local development.

🌍 Deploy with GitHub Pages

1. Open your repository on GitHub.
2. Select Settings.
3. Open Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose the "main" branch and the "/ (root)" folder.
6. Click Save.
7. Wait for the deployment to finish, then visit your published website.
